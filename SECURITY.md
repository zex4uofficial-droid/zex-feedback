# Security Policy

Zex takes security seriously.

Please do not report security vulnerabilities through public GitHub issues, discussions, pull requests, or comments.

Public reports may expose users, systems, or sensitive information before we have a chance to investigate and fix the issue.

---

## Reporting a security vulnerability

If you believe you have found a security vulnerability in Zex, please report it privately by emailing:

```text
support@zex4u.com
```
