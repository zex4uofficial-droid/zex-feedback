# Zex Feedback & Issue Tracker

Welcome to the public issue tracker for **Zex**.

This repository is used to collect public bug reports, feature requests, feedback, and product improvement suggestions from users, testers, and the community.

> This repository does not contain Zex source code.  
> Internal engineering work may be moved to private Zex repositories after triage.

---

## What you can report here

You can open an issue for:

- App bugs
- App crashes
- UI/UX problems
- Feature requests
- Performance issues
- Incorrect or confusing behavior
- Documentation issues
- Product feedback
- General support questions

---

## Do not post sensitive information

This is a **public repository**. Anyone on the internet may be able to view issues, comments, screenshots, logs, and attachments posted here.

Please do **not** include:

- Passwords
- API keys
- Access tokens
- Secret keys
- Phone numbers
- Email addresses
- Government ID numbers
- Bank/payment information
- Private user data
- Internal company data
- Full database records
- Production logs containing personal data
- Screenshots showing private information

If your issue requires private details, describe the problem without exposing sensitive information.

---

## Security vulnerabilities

Please do **not** report security vulnerabilities in public GitHub issues.

If you believe you found a security issue in Zex, report it privately instead.

Security examples include:

- Authentication bypass
- Account takeover
- Data leak
- API key exposure
- Payment or subscription bypass
- Remote code execution
- Unauthorized access to user data
- Vulnerability in encryption, storage, or backend logic

## Reporting options

Please choose the correct reporting path:

- For bugs, feature requests, and public feedback, open a GitHub issue using one of our issue templates.
- For private support, email us at support@zex4u.com.
- For security vulnerabilities, do not open a public issue. Email us privately at support@zex4u.com.
