# Zex Support

This document explains how to get help with Zex.

---

## Public issue tracker

Use this GitHub repository for public reports such as:

- Bug reports
- Feature requests
- UI/UX feedback
- Documentation issues
- General product feedback
- Reproducible app issues

Please use the correct issue template when opening a new issue.

---

## Private support

For private support, account-related questions, billing questions, or anything that should not be public, email:

```text
support@zex4u.com
```
